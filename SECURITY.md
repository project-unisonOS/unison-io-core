# Security

This service is an I/O core gateway for UnisonOS and is intended for local or tightly controlled deployments.

For overall security guidance, see:

- https://project-unisonos.github.io/reference/security/

If you discover a security issue in unison-io-core, please follow the responsible disclosure guidance in the UnisonOS security docs or open a private security advisory on GitHub rather than filing a public issue.
